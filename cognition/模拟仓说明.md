# PanWatch 模拟仓说明

本文说明模拟仓为什么会在机会池刷新后自动操作、它具体如何建仓/平仓，以及当前哪些策略参数可以配置。

## 一、为什么刷新机会池后模拟仓会有操作

机会池刷新和模拟仓交易不是同一个动作，但二者通过 `StrategySignalRun` 这张策略信号表连接。

流程是：

```text
机会页点击刷新
  -> /api/recommendations/strategy-signals/refresh
  -> refresh_strategy_signals()
  -> 写入/更新 strategy_signal_runs
  -> 模拟仓调度器下一轮扫描
  -> 读取 active + buy/add + 有入场计划的信号
  -> 自动开模拟仓
```

模拟仓调度器在服务启动时自动启动，默认每 60 秒扫描一次，并且只在 CN/HK/US 任一市场处于交易时段时扫描。也可以在“模拟盘”页面点击“立即扫描”手动触发。

所以你看到“机会池刷新后模拟仓出现操作”，本质原因是：

- 机会池刷新生成了新的 `active` 买入/加仓信号。
- 模拟仓账户处于启用状态。
- 对应市场资金比例不为 0。
- 股票当前没有未平仓模拟持仓。
- 模拟仓扫描时读取到了这些信号，并按规则建仓。

## 二、模拟仓入场规则

模拟仓扫描的是 `strategy_signal_runs`，入场条件是：

- `status = active`
- `action in ("buy", "add")`
- `entry_low` 不为空
- `entry_high` 不为空
- 该市场资金比例大于 0
- 同一只股票当前没有 open 模拟持仓

扫描时会按 `rank_score` 从高到低取前 50 条信号。同一只股票如果有多条策略信号，只会取分数最高的一条。

需要注意：当前入场不是“价格落入 entry_low/entry_high 区间才买”，而是只要求信号存在入场区间，然后用当前实时行情价建仓。`entry_low/entry_high` 主要用于判断这条信号是否有入场计划，以及映射止损/止盈比例。

## 三、仓位如何计算

模拟仓默认创建一个单例账户：

```text
初始资金：1,000,000
默认市场比例：CN 50%，HK 30%，US 20%
```

每个市场都有独立资金子池：

```text
市场可用资金 = 总初始资金 × 该市场比例 + 该市场已实现盈亏 - 该市场未平仓成本
```

单笔建仓金额按信号强度 `rank_score` 决定，占“该市场预算”的比例：

| rank_score | 单笔目标资金比例 |
| --- | ---: |
| >= 85 | 25% |
| >= 75 | 18% |
| >= 65 | 12% |
| < 65 | 8% |

股数按 100 股一手取整。如果目标资金不足一手，但该市场可用资金可以买一手，则至少买 100 股；如果连一手加交易成本都买不起，则跳过。

交易成本使用项目里的 `CostModel`：

- 佣金：双边万 2.5，最低 5 元
- 印花税：卖出单边万 5
- 过户费：双边十万分之 1
- 滑点：双边 5 bps

当前成本模型是 A 股口径，但模拟仓会把同一成本模型用于 CN/HK/US 的模拟交易，这是现阶段的简化实现。

## 四、止损、止盈和平仓规则

建仓时会记录：

- 入场价：当前实时行情价
- 止损价：优先来自信号 `stop_loss`
- 止盈价：优先来自信号 `target_price`
- 持有周期：优先来自信号 `holding_days`

如果信号有止损/止盈，模拟仓会把原信号相对入场区间中点的止损/止盈比例，映射到实际成交价上。

如果信号止损/止盈无效，则使用兜底规则：

```text
默认止损：入场价 × 0.92，也就是 -8%
默认止盈：入场价 × 1.15，也就是 +15%
```

持仓后的每轮扫描会检查这些退出条件：

1. 止损：当前价 <= stop_loss。
2. 止盈：当前价 >= target_price。
3. 移动止损：持仓最高价相对入场价浮盈达到 5% 后启用；之后如果从最高价回撤 10%，平仓。
4. 信号反转：同一股票出现最新 active 信号，且 action 为 `sell` 或 `reduce`，平仓。
5. 时间止损：持有天数达到信号 `holding_days`；如果信号没有提供，则默认 20 个自然日。
6. 手动平仓：在模拟盘页面点击持仓行的“平仓”。

同一轮扫描中新建的仓位会跳过当轮平仓检查，避免刚开仓就被同一次扫描立即关掉。

平仓后会写入 `paper_trading_trades`，并更新：

- 已实现盈亏
- 总交易次数
- 胜率
- 当前资金
- 峰值资金
- 最大回撤

## 五、模拟仓是否会真实下单

不会。

模拟仓只写本地数据库表：

- `paper_trading_account`
- `paper_trading_positions`
- `paper_trading_trades`

它不会连接券商，也不会提交真实订单。所有建仓、平仓、盈亏都是基于行情和策略信号计算出来的模拟结果。

## 六、当前可以配置什么

在“模拟盘”页面可以配置：

- 启用/暂停模拟盘。
- 重置模拟盘：清空持仓和交易记录。
- 立即扫描：手动触发一次建仓/平仓检查。
- 手动平仓：对某个 open 持仓立即平仓。
- 初始资金。
- CN/HK/US 各市场投资比例。
- 某市场比例设为 0：停止该市场新建仓；已有持仓不受影响。
- 通知设置：是否启用通知、通知渠道、实时建仓/平仓通知、盘前计划、日终摘要。

API 对应：

- `POST /api/paper-trading/account/toggle`
- `POST /api/paper-trading/account/reset`
- `POST /api/paper-trading/account/settings`
- `POST /api/paper-trading/scan`
- `POST /api/paper-trading/positions/{position_id}/close`
- `GET/POST /api/paper-trading/notify-settings`

## 七、当前不能通过页面配置什么

下面这些规则目前是代码常量或固定逻辑，页面上不能直接改：

- 扫描间隔：默认 60 秒。
- 每轮最多扫描前 50 条 active 买入信号。
- 入场条件：`active + buy/add + entry_low/high 非空`。
- 是否要求当前价落入 `entry_low/entry_high`：当前不要求。
- 单笔仓位分档：85/75/65 分对应 25%/18%/12%/8%。
- 最小交易单位：100 股。
- 默认止损：-8%。
- 默认止盈：+15%。
- 移动止损启用门槛：浮盈 5%。
- 移动止损回撤阈值：从最高价回撤 10%。
- 默认时间止损：20 个自然日。
- 交易成本模型参数。

如果要把这些变成可配置项，需要新增配置表字段或 AppSettings 配置，并在 `paper_trading_engine.py` 中读取配置。

## 八、策略本身能否配置

要分两层看。

### 1. 模拟仓执行策略

模拟仓执行策略目前只支持有限配置：

- 账户启停。
- 总资金。
- 市场资金比例。
- 通知。
- 手动扫描/手动平仓。

它的核心执行规则，如仓位分档、止损止盈、移动止损、时间止损，当前不能在页面配置。

### 2. 入场信号策略

模拟仓并不自己判断“哪只股票值得买”，它消费上游策略信号。上游信号来自：

- 机会池刷新生成的 `StrategySignalRun`。
- TradingAgents 在开启“模拟盘信号桥接”后写入的 `StrategySignalRun`。

因此，想影响模拟仓买什么，主要是影响上游信号：

- 调整机会池策略、因子、权重、筛选规则。
- 让信号保持 inactive，模拟仓不会买。
- 让 action 不是 `buy/add`，模拟仓不会买。
- 不生成 `entry_low/entry_high`，模拟仓不会买。
- 将某市场资金比例设为 0，模拟仓不会买该市场。
- 暂停模拟盘，所有自动建仓都会停止。

TradingAgents 还有一个独立开关：启用后，TA 输出 BUY/ADD 决策时会写入 `StrategySignalRun`，然后由模拟仓下一轮扫描消费。不开启该开关时，TA 不会自动给模拟仓写入信号。

## 九、如何避免刷新机会池后自动开仓

如果你只想看机会池，不想模拟仓跟随开仓，可以使用下面任一方式：

1. 在“模拟盘”页面暂停模拟盘。
2. 把不想交易的市场比例设为 0。
3. 不点击“立即扫描”，并在非交易时段查看，调度器不会自动扫描。
4. 调整上游策略，让机会池只生成 `watch/inactive`，不要生成 active buy/add。
5. 关闭 TradingAgents 的模拟盘信号桥接。

最直接的方式是暂停模拟盘；需要继续统计历史结果时再启用。

## 十、当前实现里的注意点

- 模拟仓扫描 active 信号时没有限定“最新快照日期”，而是扫描 `strategy_signal_runs` 中满足条件的 active buy/add 信号。因此旧信号如果仍然是 active，也可能被消费。
- 建仓时不判断当前价是否处在 `entry_low/entry_high` 区间，只用当前价成交。
- 同一只股票同一时间只保留一个 open 模拟持仓，不会重复加仓。
- 信号平仓只看最新 active `sell/reduce`，普通 `watch/inactive` 不会触发平仓。
- 成本模型当前是 A 股口径，跨市场模拟时只是近似。
- 模拟仓是回放和验证工具，不构成真实交易建议。
